# Phase 2 — Core PDF Manipulation: plan and status (started 2 Nov 2026)

**Status: NOT COMPLETED.**

Master Spec v2, Milestone 2 covers:
- page organization;
- the text editing foundation;
- annotations;
- watermarks;
- metadata;
- compression;
- scanning and OCR.

## Acceptance rule

A MAL capability becomes RELEASE_READY only through the **verified command adapter** (`src/suite/commands/verifiedCommands.ts`). A binding is accepted only when it meets every one of these:

1. Every clause of its requirement text in `docs/MALENJO_MASTER_SPEC_V2.md` is covered.
2. Each clause has passing acceptance checks that drive the real UI, save, and reopen the output independently with PDF.js and pdf-lib.
3. Those checks run in CI. `testing/suite/verifiedCommandEvidence.test.ts` fails if a cited check is missing.
4. Each PR has a clean Claude review and a clean Codex review, or every valid finding is fixed (owner policy, 2 Nov 2026).

Partial capabilities stay unbound and keep stating their limits.

## Slices

Each slice is one PR or more under the acceptance rule above.

1. **Done:** the adapter, its evidence register, and MAL-003–008 bound, with four new acceptance checks.
2. **Done:** MAL-001 multi-file ordered merge and MAL-002 split modes (ranges, page count, bookmarks, size).
3. **Done:** MAL-009 N-up (2/4/6/9/16 grids, sheet size and orientation, margin and spacing, row or column order) and MAL-010 batch assembly (ordered rules across files, ZIP with JSON/CSV manifest and SHA-256).
4. MAL-017–022: headers/footers, numbering, watermarks, metadata and outline. **Done:** MAL-017–020 stamps (placed upright in the visible frame of rotated and cropped pages; watermarks above or below the content), MAL-021 Info and XMP metadata (inspect, edit, custom properties, sync or remove XMP, clear), MAL-022 bookmarks (create, nest, rename, retarget, reorder, delete), links (web and page, change, remove) and a generated, linked table of contents.
5. MAL-024/025 compression and MAL-027/028 OCR/scanning. **Done for MAL-024/025** (lossless passes with a decoded-content equivalence check; image downsampling and JPEG profiles with a size report). MAL-027/028 remain unbound; their gaps are listed in the table.
6. **Done:** MAL-054/055 annotations — highlight, underline, strikeout and squiggly on the real text selection; pen, line, arrow, rectangle, ellipse, text box, callout and sticky note drawn on the page (including rotated pages); colour/opacity/width/text editing and deletion; every annotation has its own appearance stream.
7. MAL-011–016 and MAL-023: the text editing foundation. **Done so far:** content-stream editing core (tokenizer, font codec with ToUnicode/encoding/subset rules, page model of text runs, images and paths), MAL-011–016 and MAL-023. **Slice 7 done.**
